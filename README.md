## 🧑‍💻 Sobre Mim

Sou graduando em **Ciência de Dados e Inteligência Artificial** pela **Universidade Estadual de Londrina (UEL)**, com interesse em **Engenharia de Dados** e **IA Aplicada**. Atualmente atuo como estagiário de desenvolvimento na Demóbile, onde trabalho com automação de processos corporativos, modelagem BPM, levantamento de requisitos e integração de sistemas utilizando Bitrix24.

Minha trajetória combina **fundamentos sólidos em programação e engenharia de software** com uma visão analítica voltada para dados — uma combinação que me permite entender tanto a construção quanto o consumo de dados em ambientes reais.

Possuo **inglês avançado (B2)**, consolidado através de intercâmbio na EC Montreal (Canadá), e **francês básico (A2)**.
